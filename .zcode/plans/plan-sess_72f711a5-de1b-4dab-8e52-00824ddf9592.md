# Plan: MPS support + handwriting test + docs for the new OCR engine

## What I found (evidence from inspection)

1. **No MPS support** — both `devanagari_ocr.py` and `evaluate_accuracy.py` pick devices with `cuda if available else cpu`. Your Mac has MPS available (torch 2.14.1), so today everything silently runs on CPU.
2. **No trained weights** — the engine loads `devanagari_cnn.pth`, which doesn't exist. `checkpoints/best_model.pt` is from the scrapped CNN (different architecture) and cannot be reused. Without training, inference uses random weights → garbage output.
3. **Broken default paths** — `--data_dir` defaults to `./DHCD_Dataset` (doesn't exist); if training is run without an override, the code **silently creates a synthetic dummy dataset and "trains" on it**. `--image` defaults to `sample.png` and would auto-generate an English "Sample Run" placeholder. Your real inputs: `DevanagariHandwrittenCharacterDataset/` (Train/Test, 46 classes each) and `my_handwriting.jpeg`.
4. **Validation crash in the trainer** — there is no `val/` folder, so `val_path` falls back to the dataset root, where the loader finds no images → division-by-zero during validation. Needs a proper hold-out (I'll carve a stratified 10% validation split from Train, same approach as the old project; the Test set stays untouched for final evaluation).
5. **Class-name map mismatch** — `DHCD_LABEL_MAP` entries 30–32 use folder names that don't exist in this dataset copy (`character_30_mrdha_sha`, `character_31_patalo_sha`, `character_32_danta_sa`). Real folders: `character_30_motosaw` (श), `character_31_petchiryakha` (ष), `character_32_patalosaw` (स). As-is, predictions for those three classes print raw folder names instead of Devanagari characters (and श/ष are swapped).
6. **Preprocessing is fine — no changes** — I tested the full enhancement chain on `my_handwriting.jpeg`: all characters survive with shadows flattened (verified visually). An earlier suspicion of ink erosion turned out to be a measurement artifact on my side.

## Changes

- **Paths**: default `--data_dir` → `DevanagariHandwrittenCharacterDataset`, with explicit `Train`/`train` subfolder detection; default `--image` → `my_handwriting.jpeg`; remove the dummy-dataset and dummy-image fallbacks (fail loudly instead of silently training/predicting garbage).
